
### Overview
This repository showcases a collection of **hands-on cybersecurity and ethical hacking projects** focused on penetration testing, Active Directory exploitation, and network security assessments.  
Each project was conducted in a **controlled lab environment** to simulate real-world attack scenarios, demonstrate exploit methodologies, and propose actionable defense strategies.

---

## Featured Projects

### 1️⃣ Penetration Testing on Windows & Linux Systems
A comprehensive red teaming simulation targeting **Windows 7** and **CentOS 7** machines.  
Demonstrated attacks such as **Sticky Keys exploit**, **EternalBlue (MS17-010)**, **SQL Injection**, and **network pivoting** to achieve full system compromise.  
**Tools:** Nmap • Metasploit • Nikto • SQLMap • Kali Linux  
**Focus:** Vulnerability identification, exploitation, privilege escalation, and risk mitigation.

---

### 2️⃣ Active Directory Exploitation with BloodHound
Simulated an **Active Directory domain attack** on “lands.between” using **BloodHound**, **rpcclient**, and **Evil-WinRM**.  
Discovered weak credentials, abused **GenericAll permissions**, and escalated to **Domain Administrator** privileges.  
**Tools:** BloodHound • Impacket • JohnTheRipper • Evil-WinRM • Nmap  
**Focus:** AD enumeration, privilege escalation, credential abuse, and remediation recommendations.

---

### 3️⃣ Black Box Penetration Test (Enterprise Network Simulation)
Performed a **black-box penetration test** on a virtual enterprise network.  
Identified multiple vulnerabilities including **EternalBlue**, **SQL Injection**, **CMS RCE**, and **File Upload Exploits**, successfully capturing 10 hidden flags.  
**Tools:** Nessus • Metasploit • SQLMap • Nikto • Steghide • Burp Suite  
**Focus:** End-to-end exploitation, web app security, forensic analysis, and mitigation planning.
